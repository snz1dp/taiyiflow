# 快速上手

> 选择你的角色，每条路径都有明确的时间预期和里程碑。

## 你是谁？

| 角色 | 目标 | 预计时间 | 入口 |
|------|------|----------|------|
| 🎯 业务使用者 | 完成第一次 AI 对话 | 10 分钟 | [开始 →](/quick-start/for-business-user) |
| 🏢 厂商 / 集成商 | 搭建最小集成 Demo | 2 小时 | [开始 →](/quick-start/for-vendor) |

## 开始之前

无论你的角色是什么，请确认以下前提：

| 前提 | 说明 |
|------|------|
| 平台已部署 | 你的企业已完成太乙智启部署（问你的 IT 管理员） |
| 已有账号 | 管理员已为你开通账号（或你正在部署中） |
| 模型已配置 | 平台已接入至少一个大模型（管理员配置） |



## 各路径里程碑

### 业务使用者路径

```
打开应用 → 登录 → 发送第一条消息 → 尝试知识库问答 → 了解技能
```

### 厂商路径

```
理解集成架构 → 获取开发环境 → 调用核心 API → 嵌入前端页面 → Demo 验收
```
