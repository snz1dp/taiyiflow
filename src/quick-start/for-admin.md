# 管理员快速上手

> 目标：30 分钟内完成太乙智启部署，并让团队可以开始使用。
> 前提：你有一台 Linux/macOS 服务器（最低 4C8G），已安装 Docker。

## 部署前检查（3 分钟）

### 环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核+ |
| 内存 | 8 GB | 16 GB+ |
| 磁盘 | 50 GB | 200 GB+（含知识库数据） |
| 操作系统 | Linux / macOS | Ubuntu 22.04+ |
| Docker | 20.10+ | 24.0+ |
| 网络 | 可访问大模型 API | 内网模型则无需外网 |

### 检查命令

```bash
# 检查 Docker 版本
docker --version

# 检查 Docker Compose
docker compose version

# 检查可用内存
free -h  # Linux
# 或
sysctl hw.memsize  # macOS
```

## 第 1 步：获取部署包（2 分钟）

```bash
# 方式一：Docker Compose 一键部署（推荐）
git clone https://github.com/snz1/taiyiflow.git
cd taiyiflow

# 方式二：离线环境
# 联系技术支持获取离线部署包
```

## 第 2 步：配置环境变量（5 分钟）

复制并编辑配置文件：

```bash
cp .env.example .env
```

必须配置的项目：

```bash
# 数据库（默认使用内置 PostgreSQL）
DATABASE_URL=postgresql://taiyiflow:taiyiflow@localhost:5432/taiyiflow

# 至少配置一个大模型
# 示例：通义千问
DASHSCOPE_API_KEY=sk-your-api-key-here

# 服务端口
PORT=8000
```

:::warning 安全提醒
- 生产环境务必修改默认数据库密码
- API Key 不要提交到代码仓库
- 建议通过环境变量或密钥管理服务注入
:::

## 第 3 步：启动服务（3 分钟）

```bash
# 一键启动所有服务
docker compose up -d

# 查看启动状态
docker compose ps

# 查看日志（确认无报错）
docker compose logs -f --tail=50
```

预期输出：所有容器状态为 `Up`。

## 第 4 步：访问管理后台（2 分钟）

1. 浏览器打开 `http://你的服务器IP:8000`
2. 使用初始管理员账号登录（默认见部署文档）
3. 你将看到管理后台首页

## 第 5 步：配置大模型（5 分钟）

进入 **管理后台 → 模型管理**：

1. 点击「添加模型」
2. 选择模型类型（如：通义千问 / 文心一言 / OpenAI 兼容接口）
3. 填入 API Key 和接入地址
4. 点击「测试连接」确认连通
5. 设置默认模型（用户对话时使用的模型）

:::tip 多模型策略建议
- 日常对话：用轻量模型（成本低、速度快）
- 复杂推理：用旗舰模型（质量高）
- 可在流程设计器中为不同节点指定不同模型
:::

## 第 6 步：创建用户（3 分钟）

进入 **管理后台 → 用户管理**：

1. 点击「创建用户」
2. 填写姓名、账号、邮箱
3. 分配角色：
   - **普通用户**：只能对话
   - **知识库管理员**：可管理知识库
   - **管理员**：可管理所有配置
4. 点击「保存」，系统自动生成初始密码

## 第 7 步：验证部署（2 分钟）

1. 用刚创建的用户账号登录对话界面
2. 发送一条消息："你好，请介绍一下你自己"
3. 确认收到流式回复

✅ 如果收到回复，部署成功！

## 部署后建议

| 事项 | 优先级 | 说明 |
|------|--------|------|
| 修改默认密码 | 🔴 立即 | 管理员账号、数据库密码 |
| 配置 HTTPS | 🔴 立即 | 生产环境必须启用 |
| 设置备份策略 | 🟡 本周 | 数据库 + 知识库文件 |
| 配置监控告警 | 🟡 本周 | 服务健康检查 + 磁盘告警 |
| 建立知识库 | 🟢 两周内 | 上传企业文档，开启知识问答 |
| 制定使用规范 | 🟢 两周内 | 明确哪些数据可以输入 AI |
