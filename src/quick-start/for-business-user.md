# 业务人员快速上手

> 目标：10 分钟内完成你的第一次 AI 对话。
> 前提：你的企业已部署太乙智启，管理员已为你开通账号。

## 第 1 步：打开应用（1 分钟）

根据你的使用场景选择入口：

| 使用方式 | 适合场景 | 如何打开 |
|----------|----------|----------|
| **Web 界面** | 日常办公，浏览器直接用 | 访问管理员提供的地址（如 `http://ai.yourcompany.com`） |
| **桌面客户端** | 需要文件处理、语音对话 | 下载安装包，双击打开 |
| **嵌入页面** | 在现有业务系统里用 | 点击系统内的"AI 助手"入口 |

## 第 2 步：登录（1 分钟）

1. 输入管理员分配的账号和密码
2. 首次登录可能需要修改密码
3. 登录成功后进入对话界面

:::tip 忘记密码？
联系你的企业管理员重置，不需要自己注册。
:::

## 第 3 步：发送第一条消息（2 分钟）

在输入框里输入任何问题，按回车发送。例如：

```
帮我写一封项目进度汇报邮件，语气正式但友好
```

你会看到 AI **边想边回复**（流式输出），不用干等。

### 试试这些场景

| 你想做什么 | 怎么问 |
|-----------|--------|
| 写邮件 / 通知 | "帮我写一封……的邮件" |
| 总结长文 | 粘贴文本 + "帮我总结要点" |
| 翻译 | "把以下内容翻译成英文：……" |
| 头脑风暴 | "给我 5 个关于……的方案" |
| 解释概念 | "用通俗的话解释什么是……" |

## 第 4 步：尝试知识库问答（3 分钟）

如果你的企业已配置知识库，你可以直接问公司内部的问题：

```
公司的年假制度是怎样的？
```

```
差旅报销的流程是什么？
```

AI 会基于公司内部文档回答，并在回答中标注来源。

:::warning 注意
知识库问答的准确度取决于知识库中是否有相关内容。如果 AI 回答"未找到相关信息"，说明知识库中暂无该资料，可反馈给管理员补充。
:::

## 第 5 步：了解技能（2 分钟）

技能是 AI 的"扩展能力包"。在对话中，你可以：

- 输入 `/` 查看可用技能列表
- 直接描述需求，AI 会自动调用合适的技能

常见的内置技能：

| 技能 | 能做什么 |
|------|----------|
| 文件处理 | 上传 PDF/Word，让 AI 分析内容 |
| 图表生成 | 让 AI 根据数据生成可视化图表 |
| 流程图 | 让 AI 画出业务流程图 |

## 第 6 步：高效使用技巧（1 分钟）

| 技巧 | 说明 |
|------|------|
| 说清楚背景 | "我是项目经理，需要给甲方写周报" 比 "写个周报" 效果好 |
| 给例子 | "参考这个格式：……" 让 AI 模仿你的风格 |
| 分步提问 | 复杂任务拆成多轮对话，逐步细化 |
| 上传文件 | 拖拽文件到对话框，AI 可以直接分析 |
| 新建会话 | 不同话题用不同会话，避免上下文混乱 |

## ✅ 里程碑达成

恭喜你！你已经完成了：

- [x] 成功登录并发起了对话
- [x] 体验了流式回复
- [x] 尝试了知识库问答（如已配置）
- [x] 了解了技能系统
