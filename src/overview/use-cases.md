# 典型应用场景

> 这篇文档按行业和场景分类，展示太乙智启在不同业务环境中的落地方式。
> 每个场景按"痛点→方案→效果"三段式描述，帮助你快速判断是否适合自己的业务。

## 场景总览

太乙智启是通用智能体平台，以下场景按两大维度组织：

- **按能力维度**：知识问答、内容生成、流程自动化、工具操作、数据分析
- **按行业维度**：建筑工程、制造、设计创意、金融、教育、政务、软件、医疗、法律等

---

## 一、工作提效：AI 驱动专业工具

### 场景 1：CAD/BIM 设计提效

**痛点**：设计师每天花大量时间在图纸标注、图层整理、批量导出等重复操作上，真正用于设计思考的时间不足 40%。

**方案**：太乙智启通过 MCP 工具协议对接 ZWCAD / GstarCAD，设计师用自然语言描述需求，AI 自动执行：

| 操作 | 传统方式 | 使用太乙智启 |
|------|----------|-------------|
| 批量图纸标注 | 逐张打开、手动标注（30分钟/张） | "把这批图纸的标题栏统一更新"（10秒） |
| 图层规范检查 | 人工逐层核对 | "检查所有图纸的图层命名是否符合规范"（自动报告） |
| DWG 批量转换 | 手动另存为 | "将 folder 下所有 DWG 转为 PDF"（批量执行） |
| 设计说明生成 | 手写文档 | "根据图纸内容生成设计说明"（自动生成） |

**效果**：重复性操作时间减少 70%+，设计师专注核心创意。

### 场景 2：3D 建模与渲染辅助

**痛点**：Blender / FreeCAD 操作复杂，参数调整耗时，新手上手门槛高。

**方案**：太乙智启对接 Blender（Python API）和 FreeCAD（脚本接口）：

- 🎨 **Blender**：自然语言生成建模脚本、批量调整材质灯光、渲染参数自动优化、场景批量处理
- 🔧 **FreeCAD**：参数化建模辅助、工程图批量生成、BOM 清单自动提取、装配体检查

**效果**：3D 建模效率提升 3-5 倍，降低专业软件学习门槛。

### 场景 3：办公文档自动化

**痛点**：合同、报告、PPT 等文档格式繁琐，每次都要从头排版。

**方案**：太乙智启内置文档生成技能：

- 📄 合同/报告批量生成（模板 + 数据填充）
- 📊 Excel 数据分析与报表输出
- 📑 PPT 自动排版与内容生成
- 📋 会议纪要自动整理

**效果**：文档类工作时间从小时级降至分钟级。

## 二、知识问答与智能客服

### 场景 4：企业内部知识问答

**痛点**：公司制度、操作手册、技术文档散落在各处，员工找信息靠"问人"，效率低且答案不一致。

**方案**：
1. 管理员在后台创建知识库，上传 PDF/Word/Markdown 文档
2. 员工在对话框直接提问，AI 基于内部文档精准回答
3. 支持追问、多轮对话、引用溯源

**效果**：信息检索时间从平均 15 分钟降至 30 秒，答案一致性显著提升。

### 场景 5：对外智能客服

**痛点**：客服团队人力成本高，重复问题占比超 60%，响应慢导致客户流失。

**方案**：
1. 将产品手册、FAQ、政策文件导入知识库
2. 通过 JS SDK 将对话窗口嵌入官网/APP
3. 复杂问题自动转人工，AI 提供上下文摘要

**效果**：80% 常见问题自动解答，人工客服工作量降低 60%。

## 三、流程自动化

### 场景 6：审批与工单处理

**痛点**：审批流程依赖人工判断，工单分类靠经验，高峰期积压严重。

**方案**：
- 流程设计器搭建"接收→分类→判断→执行→通知"自动化链路
- AI 自动提取关键信息、匹配规则、生成处理建议
- 异常情况自动升级并通知相关负责人

**效果**：工单处理时效从小时级提升至分钟级。

### 场景 7：定时巡检与报告

**痛点**：每日/每周需要手动检查系统状态、汇总数据、编写报告。

**方案**：
- 定时任务自动触发数据收集
- AI 分析异常指标并生成巡检报告
- 报告自动推送至相关人员

**效果**：巡检报告从"人工 2 小时"变为"自动 5 分钟"。

## 四、研发效能提升

### 场景 8：代码助手与自动化运维

**痛点**：开发者在重复编码、环境配置、日志排查上花费大量时间。

**方案**：
- CLI 终端智能体：在命令行中直接对话，生成代码、执行命令、分析日志
- MCP 工具对接 Git、CI/CD、监控系统
- 技能系统封装团队最佳实践（代码规范、部署流程）

**效果**：日常开发效率提升 30-50%，新人上手周期缩短一半。

---

## 五、数据分析与洞察

### 场景 9：自然语言数据查询

**痛点**：业务人员想看数据，但不会写 SQL，每次都要提需求给数据团队。

**方案**：
- 对接数据库（MySQL/PostgreSQL/ClickHouse 等）
- 业务人员用自然语言提问："上个月华东区销售额是多少？"
- AI 自动生成查询、返回结果、输出图表

**效果**：数据获取从"提需求等 2 天"变为"问一句得答案"。
