# 太乙智启是什么

> 这篇文档帮助你在 3 分钟内了解太乙智启能为你的企业解决什么问题。
> 本指南主要从**业务使用者**和**厂商/集成商的开发者**两个视角出发，帮助你快速理解产品价值并找到落地路径。

## 一句话介绍

**太乙智启**是一个自主可控的通用多智能体应用平台，让企业用可视化的方式，把 AI 能力组合成真正能用的业务服务——不需要依赖某一家大模型厂商，不需要把数据交给第三方。

作为**通用智能体平台**，太乙智启不局限于某一垂直领域，而是通过技能扩展和工具对接，适配任意行业的 AI 落地需求。

## 它解决什么问题

企业在落地 AI 时，通常面临三个困境：

| 困境 | 太乙智启的解法 |
|------|---------------|
| **数据不能出门** | 私有化部署，所有数据留在你的服务器里 |
| **不想被一家模型厂商绑定** | 支持接入任意大模型，今天用 A，明天可以换 B，业务代码不用改 |
| **AI 能力零散，串不起来** | 可视化流程编排，把"检索→推理→生成→执行"串成完整业务流 |
| **专业工具操作繁琐重复** | 对接 Blender、FreeCAD、ZWCAD 等专业软件，用自然语言驱动复杂操作 |

## 用一个类比理解

把太乙智启想象成一个 **AI 流水线工厂**：

- 📥 **原料入口**：用户的问题、上传的文件、语音指令、系统事件
- ⚙️ **加工车间**：大模型推理、知识库检索、工具调用、多步骤编排
- 📤 **成品出口**：文本回答、生成的文档、执行的操作、推送的通知

太乙智启就是这个工厂的 **搭建平台和运行引擎**。你不需要自己造机床（训练模型），只需要在平台上把现成的能力拼装成你需要的流水线。

## 工作提效：让 AI 操作你的专业工具

太乙智启不只是"聊天机器人"。通过 MCP 工具协议和客户端工具回调机制，AI 可以直接操作你的专业软件，将重复性操作自动化：

| 专业工具 | 提效场景 |
|----------|----------|
| **Blender** | 用自然语言描述场景，AI 自动生成 3D 建模脚本、批量调整材质、渲染参数优化 |
| **FreeCAD** | 参数化建模辅助、批量生成工程图纸、BOM 清单自动提取 |
| **ZWCAD / GstarCAD** | 图纸批量标注、图层规范检查、设计说明自动生成、DWG 批量转换 |
| **Office 套件** | 合同/报告批量生成、数据透视分析、PPT 自动排版 |
| **开发工具链** | 代码生成、自动化测试、CI/CD 流程触发、日志分析 |
| **数据库/BI 工具** | 自然语言查数据、自动生成报表、异常指标预警 |

:::tip 关键价值
对于设计、工程、制造等知识密集型岗位，太乙智启将"打开软件→找到菜单→重复操作→导出结果"的分钟级流程，压缩为"一句话描述需求→AI 自动完成"的秒级体验。
:::

## 产品组成

| 组件 | 它是什么 | 谁会用 |

| **后端服务** | 核心引擎，负责 AI 编排、知识检索、流式对话 | 管理员、开发者 |
| **对话前端** | 桌面客户端 & Web 界面，员工日常使用的入口 | 所有员工 |
| **管理后台** | 可视化流程设计器、用户/模型/知识库管理 | 管理员 |
| **CLI 工具** | 终端智能体，开发者在命令行里用 | 开发者 |
| **JS SDK** | 把 AI 对话嵌入你现有的 Web 系统 | 前端开发者 |

| 能力 | 业务价值 |
|------|----------|
| 多智能体编排 | 把多个 AI 步骤串成自动化流程，替代重复人工操作 |
| RAG 知识增强 | 让 AI 基于你的内部文档回答，而不是瞎编 |

| 流式对话 | 用户不用干等，AI 边想边说，体验流畅 |
| 定时任务 | 周期性自动执行巡检、报表、通知等任务 |
| 多端协同 | 桌面端、Web、CLI、语音多入口，随时随地使用 |

## 适用行业与场景

太乙智启是通用智能体平台，适用行业远不止以下列举——任何有"知识问答、流程自动化、内容生成、工具操作"需求的场景都可以落地：

| 行业 | 典型场景 |
|------|----------|
| **建筑/工程/施工（AEC）** | CAD 图纸批量处理、设计规范检查、工程量清单生成、施工方案问答 |
| **制造业** | 设备手册问答、工单智能分类、质检报告生成、工艺参数推荐 |
| **工业设计/创意** | 3D 建模辅助（Blender/FreeCAD）、渲染参数优化、设计文档生成 |
| **金融** | 合规知识问答、合同审查辅助、研报摘要、风控规则解读 |
| **教育/科研** | 课程知识助手、论文辅助、实验数据分析、学情报告生成 |
| **政务/公共服务** | 政策文件检索、办事指南问答、公文辅助、舆情分析 |
| **软件/互联网** | 研发效能提升、技术文档生成、Code Review、自动化运维 |
| **医疗/生命科学** | 文献检索摘要、病历结构化、合规审查辅助 |
| **法律** | 法规检索、合同条款比对、案例摘要、文书起草辅助 |
| **零售/电商** | 商品描述生成、客服知识库、营销文案批量产出 |
| **物流/供应链** | 运单异常处理、调度规则问答、供应商文档管理 |
| **能源/环保** | 巡检报告生成、安全规程问答、排放数据分析 |

:::tip 通用性说明
上表仅为示例。太乙智启的技能系统和工具协议使其可以对接任何有 API 或脚本接口的系统，行业适配不受限制。
:::
