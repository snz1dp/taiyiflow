# 太乙智启是什么

> 这篇文档帮助你在 3 分钟内了解太乙智启能为你的企业解决什么问题。

## 一句话介绍

**太乙智启**是一个自主可控的多智能体应用平台，让企业用可视化的方式，把 AI 能力组合成真正能用的业务服务——不需要依赖某一家大模型厂商，不需要把数据交给第三方。

## 它解决什么问题

企业在落地 AI 时，通常面临三个困境：

| 困境 | 太乙智启的解法 |
|------|---------------|
| **数据不能出门** | 私有化部署，所有数据留在你的服务器里 |
| **不想被一家模型厂商绑定** | 支持接入任意大模型，今天用 A，明天可以换 B，业务代码不用改 |
| **AI 能力零散，串不起来** | 可视化流程编排，把"检索→推理→生成→执行"串成完整业务流 |

## 用一个类比理解

把太乙智启想象成一个 **AI 流水线工厂**：

- 📥 **原料入口**：用户的问题、上传的文件、语音指令、系统事件
- ⚙️ **加工车间**：大模型推理、知识库检索、工具调用、多步骤编排
- 📤 **成品出口**：文本回答、生成的文档、执行的操作、推送的通知

太乙智启就是这个工厂的 **搭建平台和运行引擎**。你不需要自己造机床（训练模型），只需要在平台上把现成的能力拼装成你需要的流水线。

## 产品组成

| 组件 | 它是什么 | 谁会用 |
|------|----------|--------|
| **后端服务** | 核心引擎，负责 AI 编排、知识检索、流式对话 | 管理员、开发者 |
| **对话前端** | 桌面客户端 & Web 界面，员工日常使用的入口 | 所有员工 |
| **管理后台** | 可视化流程设计器、用户/模型/知识库管理 | 管理员 |
| **CLI 工具** | 终端智能体，开发者在命令行里用 | 开发者 |
| **JS SDK** | 把 AI 对话嵌入你现有的 Web 系统 | 前端开发者 |

## 核心能力一览

| 能力 | 业务价值 |
|------|----------|
| 多智能体编排 | 把多个 AI 步骤串成自动化流程，替代重复人工操作 |
| RAG 知识增强 | 让 AI 基于你的内部文档回答，而不是瞎编 |
| 多模型支持 | 不同任务用不同模型，成本和质量都能优化 |
| MCP 工具协议 | 让 AI 能操作你的内部系统（查数据库、调接口） |
| 技能系统 | 用一份 Markdown 文件就能给 AI 加新能力 |
| 流式对话 | 用户不用干等，AI 边想边说，体验流畅 |
