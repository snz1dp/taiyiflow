# Web 对话界面

> 这篇文档介绍太乙智启 Web 对话界面的功能和操作方法。

## 访问方式

在浏览器中打开管理员提供的 Web 地址即可使用。

## 主要功能

- 流式对话：与桌面客户端一致的对话体验
- Markdown 渲染：支持代码高亮、表格、图表
- 文件上传与预览
- 知识库检索
- 移动端自适应

## 移动端适配

Web 界面支持移动端浏览器访问，自动适配小屏幕布局。
