# 桌面客户端使用指南

> 这篇文档帮助你全面了解太乙智启桌面客户端的功能和使用方法。

## 界面布局

<!-- TODO: 配截图 -->

桌面客户端主要包含以下区域：

- **左侧边栏**：会话列表、技能管理、设置入口
- **主对话区**：消息展示、Markdown 渲染、代码高亮
- **底部输入区**：文本输入、文件上传、语音输入
- **右侧抽屉**：文件预览、Diff 对比、产物管理

## 登录与账号

- 支持账号密码登录和扫码登录
- 登录后自动同步会话历史

## 对话功能

- 流式输出：AI 回答实时逐字显示
- Markdown 渲染：支持表格、代码块、Mermaid 图表、ECharts 图表
- 多轮上下文：同一会话内 AI 记住之前的对话内容
- 会话分组：按项目或主题组织对话

## 文件操作

- 上传文件：支持拖拽或点击附件按钮
- 文件预览：在右侧抽屉中预览上传的文件
- Diff 对比：查看 AI 对文件的修改差异

## 语音对话

- 点击麦克风按钮开始语音输入
- 支持实时语音识别
- 支持多种音色选择

## 技能管理

- 查看已安装技能列表
- 启用/禁用技能
- 从远程仓库安装新技能

## 常见问题

- 应用无法启动：检查系统版本兼容性
- 登录失败：确认网络连接和账号状态
