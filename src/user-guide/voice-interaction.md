# 语音对话

> 这篇文档介绍太乙智启的语音交互功能，包括语音输入、语音识别和音色管理。

## 语音输入

在对话界面点击麦克风按钮即可开始语音输入，系统会实时将语音转换为文字。

## 实时语音识别

- 支持边说边识别，实时显示转写结果
- 基于 WebSocket 实现低延迟传输

## 离线语音识别

对于已录制的音频文件，支持上传后进行离线识别。
