# 常见问题

> 这篇文档汇总了使用太乙智启时常见的问题和解决方案。

## 登录相关

**Q：登录时提示"认证失败"？**
- 确认账号密码正确
- 检查网络连接是否正常
- 尝试退出后重新登录

**Q：扫码登录无反应？**
- 确认手机和电脑在同一网络
- 确认二维码未过期（刷新重试）

**Q：长时间未使用后需要重新登录？**
- CLI 会自动使用 `persistent_token` 续期
- 如果续期失败，需要重新登录

## 连接相关

**Q：对话时一直转圈无响应？**
- 检查后端服务是否正常运行
- 检查网络连接
- 查看浏览器控制台是否有错误信息

**Q：流式输出中断？**
- 可能是网络波动，刷新页面重试
- 检查后端日志是否有异常

## 性能相关

**Q：回答速度很慢？**
- 大模型推理本身需要时间
- 知识库检索会增加少量延迟
- 联系管理员确认模型配额是否充足

## 权限相关

**Q：AI 无法访问某个文件？**
- 检查 `external_resource_access_policy` 配置
- `deny`：拒绝访问工作目录外文件
- `confirm`：访问前需确认
- `allow`：允许访问

**Q：AI 写文件时弹出确认窗口？**
- 这是 `write_confirmation_policy` 的安全机制
- 设置为 `direct` 可跳过确认
