# 文件处理

> 这篇文档介绍太乙智启中的文件上传、预览、Diff 对比和产物管理功能。

## 文件上传

- 点击输入框旁的附件按钮选择文件
- 支持拖拽文件到对话区域
- 上传的文件会作为上下文提供给 AI

上传的文件可在右侧抽屉面板中预览。

## Diff 对比

当 AI 修改了文件内容时，可以通过 Diff 视图查看变更：
- 绿色为新增内容
- 红色为删除内容

## 产物管理

AI 生成的文件（代码、文档等）会作为"产物"记录：
- 在变更列表中查看所有产物
- 支持下载产物文件
