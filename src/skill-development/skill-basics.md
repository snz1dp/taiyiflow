# 技能是什么

> 这篇文档帮助你理解太乙智启中"技能"的本质、作用和与工具的区别。

## 一句话定义

**技能 = 结构化的提示词注入**，告诉 AI 智能体在特定场景下"应该怎么做"。

## 通俗理解

把 AI 想象成一个新入职的员工：
- **技能**就是给他的"操作手册"——告诉他遇到什么情况该怎么处理
- **工具**就是给他的"办公设备"——让他有能力执行具体操作

## 技能如何影响 Agent 行为

1. 客户端发现本地技能文件
2. 发起对话时，技能内容通过 `client_skill_packages` 上送
3. 服务端将技能内容注入到 AI 的系统提示词中
4. AI 在回答时参考技能指令，按规范行事

## 技能 vs 工具

| 维度 | 技能（Skill） | 工具（Tool） |
|------|--------------|-------------|
| 本质 | 提示词文本 | 可执行的函数/服务 |
| 作用 | 告诉 AI 怎么做 | 让 AI 能做到 |
| 形式 | SKILL.md 文件 | MCP 服务/客户端工具 |
| 注入方式 | client_skill_packages | available_tools / client_mcp_servers |
| 执行位置 | AI 推理时参考 | 客户端/服务端实际执行 |

## 技能示例

```markdown
---
name: 代码审查助手
---

# 代码审查助手

当用户要求审查代码时，按以下步骤操作：

1. 先通读代码，理解整体结构
2. 检查潜在的 bug 和安全问题
3. 评估代码可读性和性能
4. 给出具体的改进建议，附带代码示例
```
