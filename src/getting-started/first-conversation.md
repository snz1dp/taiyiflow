# 第一次对话

> 这篇文档带你在 5 分钟内完成从打开应用到成功对话的完整流程。

## 前置条件

- 已完成[安装](/getting-started/installation)
- 拥有太乙智启账号（或管理员已为你创建账号）

---

## 桌面客户端

### 第 1 步：打开应用

启动太乙智启桌面客户端，你会看到登录界面。

### 第 2 步：登录

- **账号密码登录**：输入手机号/账号和密码
- **扫码登录**：点击"扫码登录"，用手机扫描二维码下载

### 第 3 步：发起对话

登录成功后进入对话界面：

1. 在底部输入框输入你的问题，例如：`你好，请介绍一下你自己`
2. 按 `Enter` 发送
3. 等待 AI 流式输出回答

### 第 4 步：试试更多能力

| 试试这个 | 怎么做 |
|----------|--------|
| 上传文件 | 点击输入框旁的附件按钮，选择文件 |
| 使用技能 | 输入 `/skills` 查看可用技能 |
| 切换模式 | 在设置中切换 ask / plan / agent 模式 |
| 语音对话 | 点击麦克风按钮开始说话 |

---

## CLI 终端

### 第 1 步：登录

```bash
./taiyiflow-cli login
```

按提示输入账号密码，或使用 `./taiyiflow-cli login qr` 扫码登录。

### 第 2 步：进入交互模式

```bash
./taiyiflow-cli
```

进入 TUI 界面后，直接输入问题即可对话。

### 第 3 步：试试任务模式

```bash
./taiyiflow-cli task "列出当前目录的文件结构并生成说明文档"
```

### 常用 TUI 命令

| 命令 | 说明 |
|------|------|
| `/about` | 查看版本信息 |
| `/login` | 切换账号 |
| `/skills` | 管理技能 |
| `/tasks` | 查看后台任务 |

---

## Web 界面

### 第 1 步：访问

在浏览器中打开管理员提供的 Web 地址。

### 第 2 步：登录并对话

与桌面客户端操作一致，输入问题即可获得回答。

---

## 对话小技巧

:::tip 让 AI 更好地理解你
- **说清楚目标**：比起"帮我写代码"，不如说"用 Python 写一个读取 CSV 并统计每列平均值的脚本"
- **提供上下文**：上传相关文件、粘贴错误日志
- **分步骤提需求**：复杂任务拆成多轮对话，逐步推进
:::

:::warning 注意
- Agent 模式下 AI 可以读写文件、执行命令，请注意工作目录安全
- 可通过 `external_resource_access_policy` 配置限制 AI 访问工作目录外的文件
:::
