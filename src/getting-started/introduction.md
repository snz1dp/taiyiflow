# 太乙智启是什么

> 这篇文档帮助你在 3 分钟内了解太乙智启的定位、能力和适用场景。

## 一句话介绍

**太乙智启**是一个开源的多智能体与 RAG（检索增强生成）应用开发平台，通过可视化的方式将各种 AI 能力组合成完整的智能服务流程，实现智能服务的快速开发和部署。

## 它能做什么

想象你有一个"AI 流水线工厂"：

- 📥 **输入**：用户的问题、上传的文件、语音指令
- ⚙️ **处理**：大模型推理、知识库检索、工具调用、多步骤编排
- 📤 **输出**：文本回答、生成的文档、执行的操作结果

太乙智启就是这个工厂的**搭建平台和运行引擎**。

## 产品组成

太乙智启由以下五个核心组件构成：

| 组件 | 说明 | 适合谁 |
|------|------|--------|
| **后端服务**（taiyiflow） | 核心引擎，负责 Agent 编排、RAG 检索、流式对话 | 平台管理员、集成开发者 |
| **对话前端**（taiyiflow-chatui） | 桌面客户端 & Web 对话界面 | 所有用户 |
| **管理前端**（dashweb） | 可视化流程设计器、用户/模型/知识库管理 | 管理员、流程设计者 |
| **CLI 客户端**（taiyiflow-cli） | 终端智能体工具，面向开发者 | 开发者 |
| **JS SDK**（taiyiflow-jssdk） | Web 页面嵌入式集成 SDK | 前端集成开发者 |

## 核心特性

- **开源可定制**：MIT 许可证，Python 驱动，完全可定制
- **多大模型组合**：支持接入多个大模型，按任务灵活组合
- **不绑定向量存储**：RAG 能力不依赖特定的向量数据库
- **MCP 协议**：支持 Model Context Protocol，可扩展本地和远程工具
- **技能系统**：声明式技能包，支持发现、安装、动态注入
- **多端覆盖**：桌面、Web、小程序、终端等多种使用方式

## 适用场景

| 场景 | 说明 |
|------|------|
| 企业知识问答 | 基于内部文档构建智能客服或知识助手 |
| 开发辅助 | 通过 CLI 在终端完成代码生成、文档整理、排障等任务 |
| 流程自动化 | 将多个 AI 步骤编排为自动化工作流 |
| 系统集成 | 通过 API/SDK 将 AI 能力嵌入现有业务系统 |
| 智能体扩展 | 开发自定义技能和 MCP 工具，扩展智能体能力边界 |
