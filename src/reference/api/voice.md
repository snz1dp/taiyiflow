## 接口列表

| 接口 | 协议 | 说明 |
|------|------|------|
| 实时语音识别 | WebSocket | 实时流式转写 |
| 离线语音识别 | HTTP | 音频文件转写 |
| 语音对话 | HTTP | 语音输入发起对话 |
| 用户声纹 | HTTP | 声纹注册与识别 |
| 音色管理 | HTTP | 系统音色配置 |
